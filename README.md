# CS210-Project
CS210 Final Project
Flight Delays And Cancellations Prediction Based on Weather

The main visualization and analysis are stored in Data_Analysis.ipynb.

Data_Compiling_Collection.ipynb was used to compile and clean all the data. It is not necessary to run. If you do want to run it, make sure to download all of flight_data and T_MASTER_CORD.csv, make sure they are in the same folder as Data_Compiling_Collection.ipynb, and simply run all cells to generate the flight database. Runtime is approximately 1 minute.

To run Data_Analysis.ipynb, download flight.db and make sure it is in the same folder as Data_Analysis.ipynb, then run all cells in the notebook. Run time is approximately 8 minutes. 

Be warned that all data files are very large and stored as lfs files.
